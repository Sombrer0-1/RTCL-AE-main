## 假设与冻结参数

第四轮 cooperative FIFO 每次准备检查尽快推理，平稳组推理平均批量约 2.1，训练变慢。一种替代机制是把主机准备中的短暂继续执行视作可控服务休假：以近期已释放请求估计下一步可合并批量，比较现在与下一服务机会的摊销推理成本；二次等待惩罚与 0.35*SLO 经验响应包络限制攒批。准备阶段的下一机会为 min(8 ms, SLO/4)，迭代边界下一机会为一个完整训练步。预计未来到达只用于成本估计，实际执行绝不服务未到达样本。

已到达队列 Q，近期 200 ms 到达数估计 lambda；预测下一步等待 d 后的批量 B'=min(32, floor(Q+lambda*d))。候选分数：

`score(d,B) = predicted_infer_cost(B)/B + 0.1*cost(1)*((oldest_age+d+predicted_infer_cost(B))/(0.35*SLO))^2`。

只有“下一操作经验上界 + 推理经验上界 + oldest_age”仍在包络内且分数更低才继续执行。满 32 请求或训练结束直接服务；所有超时请求仍处理、计分。经验上界不是 WCET 或硬实时保证。第一版参数在 GPU pilot 前固定；pilot 只查集成/正确性，不按优胜者调阈值。

学习消融：133 参数 9→12→1 NumPy CPU MLP，预测有界 ±log(4) 推理服务耗时对数残差。输入为任务类型、批量、批量平方、log批量、近期训练/推理成本、已到达请求率、队列长度、服务阶段；只使用完成推理的耗时监督，不用准确率或未来请求。前 32 次推理观测用解析预测；256 记录 replay，每 8 观测做一批最多 16 样本 SGD，学习率 .03，Huber 梯度截断 .5，私有 RNG。训练耗时与所有经验安全过滤保持解析版本相同；网络只影响何时值得合并服务。

记录在线更新前的对数 MAE（相对解析基线）、网络改变决策次数、总体控制耗时。更低预测误差本身不算调度成功，必须检查端到端指标。

## 对照与评价

同轮重新运行 certified FIFO、cooperative FIFO、cooperative predictive、cooperative predictive_neural。后两者的执行结构、检查间隔和经验过滤完全相同，差别仅为学习预测。

pilot：seed 19，ResNet20 / 2 epochs / steady / 6000 请求 / 30s / 100ms，后三组，共 3 次。正式矩阵：ResNet20 / 2 epochs / steady / 100ms 与 ResNet56 / 1 epoch / bursty / 33ms，seed 211、307，四组，共 16 次；轮换执行顺序。独立验证：seed 419，上述两设置的 predictive / predictive_neural，共 4 次；不能混合阶段墙钟结果。

各次保留全部 6000 不重复请求、1580/790 更新、最终完整 10000 样本测试、实际命令、环境及主机负载。配对最终模型及请求哈希必须一致。指标为总耗时、训练完成时间、P95/P99、超时率、goodput、在线/最终准确率与控制开销；逐请求重算核验。

正收益要求明确归因：与同一解析算法比较学习的边际效果，并同时报告吞吐、延迟和准确率代价；两种子和一个独立种子只提供探索证据，不称统计显著性。若网络预测不改善、很少改变决策或性能不稳定，记录为失败，不筛去不利结果。
