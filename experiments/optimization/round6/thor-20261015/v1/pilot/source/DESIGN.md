# 第六轮：校准神经成本与两段批处理前瞻

目标是在第五轮 133 参数神经残差基础上，让学习结果参与实际调度决策，并验证其净收益。环境沿用本机 Thor／Conda rtcl，不改训练量、Replay、训练 batch、数据顺序或模型结构。

## 算法

`stream_lookahead` 与 `stream_lookahead_neural` 使用相同的算法结构。后者沿用 9→12→1 NumPy CPU MLP，并将监督从仅推理扩展为训练＋推理耗时；前者移除网络，构成网络边际贡献的对照。

1. 点预测为原 EWMA 成本，神经版乘以有界对数残差。训练／推理各完成 32 次观测后才启用其学习预测。
2. 分操作维护最近 128 个执行前预测的对数误差，每 8 个观测更新单侧 95% 经验分位数。上界为点预测乘误差余量，余量不小于零；冷启动使用旧经验上界。神经版同时维护解析残差序列，以比较同一状态下移除网络的动作。
3. 候选为立即服务整个队首批次、先服务 1/2/4/8/16 个 FIFO 请求后再服务该批剩余请求，以及继续一次训练／准备操作后攒批。每个前瞻只覆盖队首至多 32 个已到达请求。
4. 拆批仅在两段计划预测的超时数严格更少时进入比较；分数包含每请求摊销推理成本、二次响应时间惩罚及超时惩罚。当前到达率只用于攒批预测，实际执行不访问未来请求。
5. 延后服务仍受 `0.35*SLO` 经验包络约束，校准后的训练与推理成本参与该判断。所有请求保留、逾期仍服务；没有早退、降低训练量或预测准确率反馈。

分数以单请求推理均值为尺度：`total_infer_cost/n + unit*(0.1*mean((response/(0.35*SLO))^2) + 4*mean(miss + normalized_tardiness))`。攒批项按预测的未来 batch 摊销推理成本；两段计划支付两次推理成本。

操作开始时冻结点预测、上界及特征，结束后才计分、校准和学习，避免主机准备中的嵌套推理更新网络后重算训练预测。误差校准是启发式滚动校准，没有套用 conformal coverage 或 WCET 定理。二段计划只是重新决策前的成本近似，第二段不被强制执行。

## 冻结实验与归因

- pilot：seed 19，两种原设置，lookahead／lookahead_neural，共 4 次。检查集成、校准、实际动作变化与开销；如修改算法，以新输出目录和设计说明重新开始，不混合版本。
- main：seed 211、307，两设置，cooperative FIFO／旧 predictive_neural／lookahead／lookahead_neural，共 16 次，轮换顺序。
- holdout：仅当候选值得继续验证时，seed 419，两设置的 lookahead／lookahead_neural，共 4 次，单独报告。
- 设置与第五轮一致：平稳 ResNet20／2 epochs／100 ms，突发 ResNet56／1 epoch／33 ms；6000 唯一请求／30 秒；训练 batch64，推理最多32，完整最终10000样本测试。各次保留全部1580／790次训练更新。
- 同设置、同种子的最终模型与到达轨迹应一致；按逐请求记录重算延迟、超时率、在线准确率、按时正确率和平均 batch。完整成本和决策记录用于核查网络实际改变哪些动作。
- 新算法与 FIFO／旧神经版比较；网络边际贡献只以 lookahead_neural 对 lookahead 的配对结果判断。预测误差降低、拆批数或动作分歧增加都不单独算成功。
- 同时报总墙钟、训练完成时间、P95／P99、超时、按时正确率及控制耗时。收益若依赖损害其他指标，应明确给出取舍；小种子数只作探索性证据。负结果与失败记录保留。

## 参考与创新边界

[Decision-focused learning](https://ojs.aaai.org/index.php/AAAI/article/view/3982) 强调预测指标与决策目标可能错位；本轮不实现其优化层反传。[Adaptive Conformal Inference](https://papers.nips.cc/paper_files/paper/2021/hash/0d441de75945e5acbc865406fc9a2559-Abstract.html) 提供在线误差校准的相关背景，本轮只实现固定窗口残差分位数，不宣称其理论保证。候选创新是面向合作式 CL 执行的校准成本、期限挽救与神经消融组合，文献新颖性与实用收益均待验证。
